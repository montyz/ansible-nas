# Audioserve

Homepage: <https://github.com/izderadicka/audioserve>

Simple personal server to serve audio files from directories. Intended primarily for audio books, but anything with decent directories structure will do. Focus here is on simplicity and minimalist design.

## Usage

Set `audioserve_enabled: true` in your `inventories/<your_inventory>/nas.yml` file.

The Audioserve web interface can be found at <http://ansible_nas_host_or_ip:3000>.
